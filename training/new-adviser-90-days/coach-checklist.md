# Coach Checklist: Day 7, 30, 60 and 90

**For:** Team leaders coaching the January 2027 intake
**Dates:** Day 7 = Sun 10 Jan 2027 (hold it Sat 9 or Mon 11 Jan) · Day 30 = Tue 2 Feb · Day 60 = Thu 4 Mar · Day 90 = Sat 3 Apr

**How to use this checklist**
- Each check is a 45–60 minute one-to-one. Start with what's going well.
- Tick each item **Met / Working on it / Not yet**. "Not yet" is fine early on. It tells us where to help.
- We check **skills, habits, quality and wellbeing**. We never set or review **income** targets in these checks.
- Any **compliance red flag** (marked 🚩) is raised the same day with the principal's compliance team. It is not left until the next check.
- Keep notes in the firm's approved system. No client data in personal notes.

Source references point to `sources.md`.
