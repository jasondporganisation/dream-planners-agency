## Format of each slide

```
### Slide N — Title   (timing)
- 3–5 bullets (what's on screen)
Speaker notes: what the facilitator says / watches for
```

Each session has **one interactive activity** (role-play, case study or quiz) with the answers or a model answer for the facilitator.
